## 2. 风险登记册（Risk Register）

**风险等级** = 发生概率 × 影响程度

| 等级 | 判定标准 |
|---|---|
| 🔴 高 | 概率 ≥ 中 且 影响 ≥ 严重 |
| 🟡 中 | 其余组合 |
| 🟢 低 | 概率低 且 影响轻微 |

### 2.1 技术风险

| 编号 | 风险 | 概率 | 影响 | 等级 | 缓解措施 | 责任人 |
|---|---|---|---|---|---|---|
| **TR-01** | Cloudflare Pages 免费政策变化或 `pages.dev` 域名在大陆被限制 | 中 | 严重 | 🔴 | ① 已备案域名可随时绑定 Cloudflare；② 备选：迁移到国内 OSS + CDN（需备案） | 用户 |
| **TR-02** | Supabase 免费项目长期不用被暂停 | 中 | 中 | 🟡 | ① 定期登录使用；② 定期导出 `cards_progress` 备份 | 用户 |
| **TR-03** | 词库数据在 Supabase 侧丢失 | 低 | 中 | 🟡 | 词库本身在应用内（不依赖云端）；仅学习进度在云端 → 定期导出 | 用户 |
| **TR-04** | Service Worker 缓存导致用户长期用旧版 | 高 | 中 | 🟡 | 已 bump 至 v17；导航改 network-first + `controllerchange` 自动刷新，通常自动生效；文档仍提醒必要时 `Ctrl+F5` | 开发 |
| **TR-05** | 浏览器 TTS 语音包缺失导致无发音 | 低 | 中 | 🟢 | Windows 需安装英语语音包；文档说明排查步骤 | 用户 |
| **TR-06** | jsdelivr CDN 不可达导致登录失效 | 中 | 中 | 🟢 | ✅ 已本地化 `vendor/supabase.js` 同源加载，不再依赖 jsdelivr | 开发 |
| **TR-07** | 单文件 HTML 持续膨胀（当前 900KB） | 中 | 低 | 🟢 | 若超过 2MB，考虑拆分为多文件 + HTTP/2 | 开发 |
| **TR-08** | 无自动化测试覆盖异步泄漏类 bug | 高 | 中 | 🟡 | 已加代码层防御（回合身份校验）；可引入 Playwright 时序测试 | 开发 |

## 6. 维护约定

1. **发现新问题**：立即登记，分配编号（KN-XX / TR-XX / DR-XX / SR-XX / OR-XX）
2. **问题解决**：移到 §4「已关闭的风险」，注明关闭方式与版本
3. **每次发版**：重新评估各风险的等级（概率与影响会随时间变化）
4. **优先级排序**：🔴 高等级风险必须在下个版本处理或明确接受并记录理由
