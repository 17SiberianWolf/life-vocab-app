# 数据字典 · 词库规范

| 项 | 内容 |
|---|---|
| 项目 | 单词碰碰乐 life-vocab-app |
| 版本 | v1.0.0 |
| 数据规模 | **3230 张卡 / 25 主题 / 2700+ 唯一词条** |
| 数据文件 | `data/cards.json`、`data/topics.json` |

---

## 1. 数据模型总览

```
topics.json (25)  ──1:N──>  cards.json (3230)
   topic_id              topic
   subscenes[]           scene   ── 子分类（引用 subscenes[].id）
                         sc      ── 场景标签（自由文本，用于展示）
```

**两张表通过 `topics.topic_id` = `cards.topic` 关联。**

## 2. cards.json 数据字典

### 2.1 字段总表

| # | 字段 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|---|
| 1 | `id` | int | ✅ | 全局唯一自增 ID，从 1 开始 | `1` |
| 2 | `m` | string \| null | ❌ | 早期模块编号（**已废弃**，仅 590 张老卡有值） | `"L1"` |
| 3 | `topic` | string | ✅ | 所属主题 ID，外键→`topics.topic_id` | `"kitchen"` |
| 4 | `en` | string | ✅ | **英文词条**（单词/短语/句子关键词） | `"knife"` |
| 5 | `zh` | string | ✅ | **中文释义** | `"刀 / 菜刀"` |
| 6 | `ex` | string | ✅ | **英文例句** | `"Please hand me the knife..."` |
| 7 | `ex_zh` | string | ✅ | **例句中译** | `"请把刀递给我，我好切面包。"` |
| 8 | `sc` | string | ✅ | 场景标签（展示用） | `"烹饪-备菜"` |
| 9 | `tip` | string | ❌ | 记忆提示/扩展用法 | `"chef's knife 主厨刀..."` |
| 10 | `difficulty` | int \| string | ✅ | 难度（见 §2.3） | `2` |
| 11 | `tags` | string[] | ❌ | 自由标签 | `["tool","cooking"]` |
| 12 | `scene` | string | ❌ | **子分类 ID**，外键→`topics.subscenes[].id`，用于浏览页 pill 筛选 | `"order"` |
| 13 | `audio_word` | string | ❌ | mp3 路径（**构建时剥离**，见 §5） | `"audio/word/kitchen/1.mp3"` |
| 14 | `audio_example` | string | ❌ | 同上 | |
| 15 | `audio_word_slow` | string | ❌ | 同上 | |
| 16 | `audio_example_slow` | string | ❌ | 同上 | |

### 2.2 字段填充率（当前实测）

| 字段 | 填充率 | 说明 |
|---|---|---|
| `id` / `topic` / `en` / `zh` / `ex` / `ex_zh` / `sc` / `difficulty` | **100%** (3230/3230) | 核心必填字段，无缺失 |
| `tags` | 95.4% (3082/3230) | 部分扩充卡未打标签 |
| `tip` | 23.2% (750/3230) | 仅精编卡（id ≤ 748）填写 |
| `m` | 18.3% (590/3230) | 已废弃字段，保留兼容 |
| `audio_*` | 100%（源文件）/ 0%（构建产物） | 构建时按配置剥离 |

### 2.3 `difficulty` 取值域

| 值 | 含义 | 数量 |
|---|---|---|
| `1` | 入门（生活高频基础词） | 538 |
| `2` | 基础（**默认**） | 1611 |
| `3` | 进阶 | 859 |
| `4` | 高阶 | 67 |
| `5` | 专业 | 7 |
| `"B"` | 商务专属标记（早期商务卡遗留） | 148 |

> ⚠️ `"B"` 是字符串，与其他整数值混用属**历史遗留**。应用内未做难度筛选，暂不影响；若未来要按难度筛选，需先统一类型。

### 2.4 `en` 字段规范（重要）

**这是最容易出错的字段**，直接决定游戏体验：

| 规则 | 说明 | 正例 | 反例 |
|---|---|---|---|
| **长度 ≤ 30 字符** | 消消乐/连连看需要短文本，太长会撑破卡片 | `"make ends meet"` | `"I would like to make a reservation for two people at 7 pm"` |
| **单词卡用原形** | 不加冠词、不变形 | `"knife"` | `"a knife"` / `"knives"` |
| **句卡用核心短语** | 完整句子放 `ex`，`en` 只放关键片段 | `"I'd like to book a table"` | 整句长对话 |
| **不含中文** | `en` 与 `ex` 必须是纯英文 | `"mapo tofu"` | `"mapo tofu 麻婆豆腐"` |
| **美式拼写优先** | 保持一致性 | `"color"` | `"colour"` |

### 2.5 `ex` / `ex_zh` 规范

- `ex`：**完整自然的英文句子**，能体现该词的典型用法
- `ex_zh`：**完整中文翻译**，与 `ex` 严格对应
- 翻译要**自然口语化**，不要逐字直译
  - ✅ `"请把刀递给我，我好切面包。"`
  - ❌ `"请递给我刀以至于我可以切面包。"`

### 2.6 `sc` 与 `scene` 的区别（易混淆）

| 字段 | 用途 | 是否用于筛选 | 格式 |
|---|---|---|---|
| `sc` | **展示**在词卡上的场景标签 | ❌ 否 | 自由文本，如 `"烹饪-备菜"` |
| `scene` | 浏览页顶部 **pill 筛选** | ✅ 是 | 必须是 `topics.subscenes[].id` 之一 |

> 新增卡片时，若该主题定义了 `subscenes`，**必须**填 `scene`，否则该卡在筛选时会被漏掉。

## 3. topics.json 数据字典

| # | 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| 1 | `topic_id` | string | ✅ | 主题唯一标识（英文小写下划线），被 `cards.topic` 引用 |
| 2 | `name_zh` | string | ✅ | 中文名 |
| 3 | `name_en` | string | ✅ | 英文名 |
| 4 | `icon` | string(emoji) | ✅ | 主题图标 |
| 5 | `order` | int | ✅ | 排序权重（越小越靠前，`business` 为 0 置顶） |
| 6 | `color` | string(hex) | ✅ | 主题主色 |
| 7 | `tags` | string[] | ✅ | 主题标签 |
| 8 | `blurb` | string | ✅ | 一句话说明（显示在主题卡片） |
| 9 | `card_count` | int | ✅ | 卡片数（**构建时自动更新**，手改无效） |
| 10 | `subscenes` | object[] | ❌ | 子分类定义，见下 |

### 3.1 `subscenes[]` 结构

```json
{
  "id": "order",              // 子分类 ID，被 cards.scene 引用
  "name_zh": "🍽 点餐用语",    // pill 显示名
  "module": "order"           // 模块标记（商务主题用 M1/M2...，其余同 id）
}
```

## 5. 构建期数据变换

`build_index.py` 在生成 `index.html` / `dist/index.html` 时会做以下变换：

| 变换 | 触发条件 | 效果 |
|---|---|---|
| **剥离音频路径** | `build-config.json` 的 `audio.embed = false` | 删除 4 个 `audio_*` 字段，产物从 494KB → 344KB |
| **更新 card_count** | 总是 | 按实际卡片数重算 `topics[].card_count` |
| **内联进 HTML** | 总是 | 写入 `<script id="appData" type="application/json">` |

**当前配置**（`build-config.json`）：

```json
{
  "audio": { "embed": false },
  "supabase": { "enabled": true, "url": "...", "anon_key": "..." },
  "pwa": { "install_prompt_enabled": true }
}
```

> `audio.embed` 改为 `true` 即可恢复 mp3 路径（需同时上传 `audio/` 目录）。

## 6. 词库扩充规范（加词必读）

### 6.1 扩充流程

```
① 在 data/expansion/ 新建 batch_XX_<name>.json
② python expand_vocab.py --dry     # 试运行，检查会新增多少条
③ python expand_vocab.py           # 正式合并（自动备份 + 去重）
④ python expand_vocab.py --stats   # 查看统计
⑤ python build_index.py            # 重新构建（必做！）
⑥ sw.js 的 CACHE_NAME +1          # 必做！否则用户拿不到新词库
⑦ 跑测试 + git push
```

### 6.2 批次文件格式

```json
{
  "topic": "chinese_food",          // 目标 topic_id（必须已存在）
  "scene_default": "huabei",        // 可选：批次级默认 scene
  "difficulty": 2,                  // 可选：批次级默认难度
  "tags": ["food"],                 // 可选：追加标签
  "items": [
    ["en", "zh", "ex", "ex_zh", "sc", "scene", "tip"]
  ]
}
```

### 6.3 `items[]` 元素字段顺序（**重要**）

| 索引 | 字段 | 类型 | 说明 |
|---|---|---|---|
| `[0]` | en | string | **必填** |
| `[1]` | zh | string | **必填** |
| `[2]` | ex | string | **必填** |
| `[3]` | ex_zh | string | **必填** |
| `[4]` | sc | string | 场景标签 |
| `[5]` | scene | string | 子分类 ID（若缺则回退 `scene_default`） |
| `[6]` | tip | string | 记忆提示 |

> ⚠️ **历史坑**：早期版本 `[5]` 被解析为 `tip`，导致 `scene` 全部回退默认值（子分类筛选失效）。
> 已于 v1.0 修正为 `[5]=scene / [6]=tip`。**新增批次必须按此顺序。**

### 6.4 去重规则

- **去重键**：`(en.lower(), topic)`
- **跨主题重复允许**：如 `bus` 同属 `transport` 和 `travel`，各存一张（合理）
- **同主题重复拒绝**：合并时自动跳过
- 当前状态：同主题重复 **0 条**，跨主题重复约 337 条（预期内）

### 6.5 质量红线（合并前自检）

- [ ] `en` / `zh` / `ex` / `ex_zh` 四个字段**全部非空**
- [ ] `en` 和 `ex` 中**不含中文字符**
- [ ] `en` 长度 ≤ 30 字符（游戏卡片显示考虑）
- [ ] `scene` 值确实存在于该主题的 `subscenes[].id` 中
- [ ] 例句翻译自然口语化，非机翻腔

### 6.6 质量校验脚本

```bash
python - <<'PY'
import json, collections, re
c = json.load(open('data/cards.json', encoding='utf-8'))

# 1. 必填字段
miss = collections.Counter()
for x in c:
    for f in ('en','zh','ex','ex_zh','topic'):
        if not str(x.get(f,'')).strip(): miss[f] += 1
print('必填字段缺失:', dict(miss) or '无 (100%)')

# 2. 同主题重复
g = collections.defaultdict(int)
for x in c: g[(x['en'].strip().lower(), x['topic'])] += 1
print('同主题重复:', sum(1 for v in g.values() if v > 1))

# 3. 英文混杂中文
bad = [x['en'] for x in c if re.search(r'[\u4e00-\u9fff]', x.get('en',''))]
print('en 含中文:', len(bad), bad[:5])
PY
```
