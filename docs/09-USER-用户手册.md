## 1. 三分钟上手

### 1.1 打开应用

浏览器访问 **https://life-vocab-app.pages.dev**，无需安装即可使用。

**强烈建议「安装到桌面」**（推荐）：
- **电脑（Chrome/Edge）**：地址栏右侧出现 ⊕ 或显示器图标 → 点击 → 「安装」。或页面右下角弹出「添加到桌面」提示条时点「安装」
- **手机**：浏览器菜单 → 「添加到主屏幕」

安装后有自己的桌面图标、独立窗口，启动更快，**断网也能用**。

> 💡 应用更新后通常**自动刷新**即生效（Service Worker 接管页面后自动重载，见 §8.1）。若仍看到旧界面，按 **Ctrl + F5**（Mac 用 Cmd + Shift + R）强刷即可。

### 1.2 第一次使用建议流程

```
① 打开应用
    ↓
② 点右上角「设置」→ 确认发音音色（默认 en-GB 英式）
    ↓
③ 回「主题」页 → 选一个你最需要的主题（比如「商务汇报」或「工业现场」）
    ↓
④ 点「📖 浏览」先过一遍词卡，混个眼熟
    ↓
⑤ 点「⚔ 碰碰乐」开始玩 —— 这是最推荐的入门游戏
    ↓
⑥ 之后每天打开「今日复习」，先清掉红色徽标的任务
```

## 4. 五种游戏玩法

### 4.1 ⚔ 碰碰乐（推荐入门）

- 上方一排中文、下方一排英文（或反之），点击配对
- 配对正确 → 发音 + 卡片消失；错误 → 记一次错误
- **计分**：基础分按用时和错误次数折算
- 顶部有「🔊 连读」按钮，可依次朗读全部英文单词

### 4.2 🔊 听音

- 播放单词发音 → 从 4 个中文选项里选
- **练听力的主力游戏**，适合通勤时玩
- 答对/答错都会显示完整例句

### 4.3 🧠 连连看

- 翻牌记忆配对，中英成对
- 计步数和时间，步数越少分越高
- 适合已经眼熟但还没记牢的词

### 4.4 ⬇ 消消乐

- 单词从上方下落，下方 4 个中文选项
- 选对消除，落到底部或选错 → 掉一条命（共 3 条）
- **最有紧张感**，适合复习已经认识的词

### 4.5 🎙 跟读

- 点麦克风 → 朗读屏幕上的英文 → 系统用浏览器语音识别打分
- 显示：得分、识别出的文本、发音建议
- ⚠️ 需要授权麦克风；识别精度取决于浏览器的语音识别服务

### 游戏通用规则

- **切换主题/退出游戏**：点顶部「主题」按钮即可立即退出，游戏会自动停止（不会有声音残留）
- **发音**：单词、例句、慢速三种。手机端统一走同源在线发音（例句**整句自然朗读**：百度翻译 TTS 整句合成、Google 兜底，不再逐词拆读；单词走有道 dictvoice 双口音回退）
- **标记**：游戏中答对 → 进 SRS 队列；答错 → 进错题本

## 6. 今日复习与每日新词

### 6.1 徽标含义

「今日复习」按钮上的红色数字 = **SRS 到期需要复习的卡 + 错题本的词**。

> **它不包含没学过的新词。** 新词按「每日新词额度」单独引入，不会让数字虚高。

### 6.2 每日新词额度

- 默认 **每天 10 个新词**，跨天自动重置
- 学满后「今日新词」区会显示「✅ 今日额度已用完，明天再来」
- 复习队列 + 新词额度都清空时，显示「🎉 今日任务全部完成」

**为什么要限量？** 词库 3230 张，如果一次性全推给你，任务永远做不完、永远没有「完成」的成就感。每天 10 个，约 10 个月自然学完，每天都能清完。

### 6.3 复习间隔（SRS）

答对后系统按 SM-2 算法安排下次复习时间：

| 状态 | 间隔 |
|---|---|
| 第 1 次答对 | 1 天 |
| 第 2 次答对 | 3 天 |
| 第 3 次答对 | 7 天 |
| 第 4 次及以后 | 15 天 |

答错 → 难度降级，很快再见到它。

## 8. 🎙 跟读与发音设置

### 8.1 发音

走**浏览器内置 TTS**（无需下载音频文件），失败时自动切换**在线发音**兜底：

- 设置里可切换音色（推荐 `en-GB` 英式，贴合欧陆商务习惯）
- 语速 3 档：0.85 / 1.0 / 1.2
- **发音方式**（v1.0.1 新增）：
  - `自动`（默认）：手机端直接用在线发音（经本站同源代理，最稳），桌面端优先本地语音
  - `仅本地语音`：完全离线，不联网（仅桌面端可靠）
  - `仅在线音频`：走本站同源 `/tts` 代理，音质稳定，需要联网

> **发音没声音？** 先检查：① 系统音量；② 耳机/音箱是否正确插入（蓝牙耳机可能未连接）；③ 浏览器是否静音了标签页。应用本身不控制音量输出设备。
> 在线发音已改为**与本站点同源**（`life-vocab-app.pages.dev/tts`），不再依赖任何外部域名，手机运营商不会再拦截。单词走有道、例句走百度翻译 TTS（主）+ Google（备）整句合成。

#### 手机端听不到发音的排障步骤（v1.0.3）

1. **先刷新页面**：把应用「添加到主屏幕」的，Service Worker 已到 `v16` 并启用 **network-first + `controllerchange` 自动刷新**；正常情况下会自动取到新页面，若仍异常**再刷新一次**即可。
2. **点设置页「🔊 发音自检」**——会播放一句测试语音，并弹出当前环境信息（平台、
   Web Speech 支持、可用音色数量、当前音色、最近错误）。按弹窗结果对应处理：
   - `Web Speech: 不支持` → 用的是微信/QQ 内置浏览器，本地语音不可用，**自动会走在线发音**，无需改设置
   - `可用音色: 0 个` / 有音色仍无声 → 现在默认已走同源在线发音，通常无需处理；若仍无声，把发音方式明确设为**「仅在线音频」**
3. 若自检提示"在线发音加载失败"：说明本站点 `/tts` 接口暂时不可达（极少见），可稍后重试或切「仅本地语音」（仅桌面可靠）。

### 8.2 跟读

- 需要麦克风权限
- 识别走浏览器 Web Speech API（Chrome/Edge 效果最好）
- 分数仅供参考，重点看「识别出的文本」——如果识别结果和你说的差很多，说明发音需要调整

## 9. 云同步（多设备使用）

### 9.1 注册/登录

点右上角「登录」，用**邮箱 + 密码**注册（不需要邮箱验证，注册后即可用）。

### 9.2 同步内容

登录后会同步：
- 每张卡的学习状态（熟练度、下次复习时间）
- 错题本
- 设置项
- 跟读得分记录

**不同步**：词库本身（词库打包在应用里，所有人共享同一份）

### 9.3 同步时机

- 登录后自动拉取云端数据
- 每次答题后自动推送（离线时进入队列，联网后自动补传）
- 多设备冲突时按**最后写入优先**

### 9.4 换设备/换电脑

在新设备打开同一个网址 → 登录同一个账号 → 进度自动回来。

## 11. 常见问题（FAQ）

**Q：更新后看到的还是旧界面 / 词库没变？**
A：通常应用更新后会**自动刷新**生效（Service Worker 接管后自动重载）。若仍看到旧界面，按 **Ctrl + F5** 强制刷新（PWA 离线缓存所致）。

**Q：发音没声音？**
A：① 检查系统音量和耳机/音箱连接（蓝牙耳机可能未真正连上）；② 浏览器标签页是否被静音；③ 换到 Chrome/Edge 试试。

**Q：跟读打不了分？**
A：① 需要授权麦克风；② 必须用 Chrome/Edge（Safari/Firefox 的语音识别支持不完整）；③ 检查网络（语音识别需要联网）。

**Q：换电脑后进度没了？**
A：需要先**登录同一个账号**。未登录时数据只存在当前浏览器，换设备/清缓存都会丢。

**Q：今日复习数字一直不降？**
A：这个数字只统计「真复习」（到期 + 错题），不包含新词。如果一直不降，检查错题本是不是积累了大量词——把错题清掉数字就降了。

**Q：手机能用吗？**
A：能。浏览器打开网址 → 「添加到主屏幕」即可像 App 一样用。跟读功能在手机上需要授权麦克风。

**Q：断网能用吗？**
A：能玩（词库完全在本地），但**云同步和语音识别需要联网**。断网时的学习进度会暂存，联网后自动同步。

**Q：数据丢了怎么办？**
A：① 如果登录过账号 → 重新登录即可恢复；② 设置里可以导出 JSON 备份，建议定期导出。

## 附录：学习建议路径

**如果你的目标是「能开口和外国同事交流」（推荐主线）：**

1. **第 1–2 周**：「商务汇报」主题 + 碰碰乐，先把工作场景的话过一遍
2. **第 3–4 周**：加「职场办公」「功能表达」，练句式
3. **持续**：每天清「今日复习」，额度内引入新词
4. **每月**：用「🎙 跟读」自检发音，重点练识别不准的词

**如果你的目标是「扩充词汇量」：**

1. 按主题顺序推进，先「学术雅思」（315 张，覆盖最全）
2. 再扩展到「社会传媒」「天气环境」「学习教育」（雅思写作高频话题）
3. 生活类主题作为调剂
