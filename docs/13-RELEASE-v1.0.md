## 5. 使用说明

### 5.1 新用户

1. 访问 https://life-vocab-app.pages.dev
2. 建议「安装到桌面」（地址栏右侧图标）
3. 选主题 → 开始学习

### 5.2 已有用户（升级到 v1.0）

> 当前版本已演进到 **v1.0.7**，后续 v1.0.1–v1.0.7 的发音修复与架构调整见 [CHANGELOG](./CHANGELOG.md)。

应用更新后通常**自动刷新**即生效（Service Worker 导航 network-first + `controllerchange` 自动重载）。若仍看到旧界面，按 `Ctrl + F5` 强制刷新一次（Mac：`Cmd + Shift + R`）。

原因（历史 v1.0 场景）：应用使用 PWA 离线缓存，不强制刷新会一直加载旧版本，表现为：
- 主题数还是 11 个
- 今日复习还是显示 2293
- 修复的 bug 依然存在

### 5.3 首次登录用户

点右上角「登录」→ 注册邮箱账号 → 进度开始云端同步。

> 未登录也能完整使用，但数据只存在当前浏览器，换设备/清缓存会丢。

## 6. 已知问题

| 编号 | 问题 | 影响 | 规避方式 |
|---|---|---|---|
| KN-01 | Supabase API 国内访问偶发慢 | 同步延迟，不影响学习 | 同步是后台异步，不阻塞 |

| KN-04 | 跟读识别依赖浏览器 Web Speech API | 非 Chrome/Edge 效果差 | 用 Chrome/Edge |
| KN-05 | 无 CSP 响应头 | 理论 XSS 风险 | 无外部脚本注入点，风险极低 |

详见 [14-已知问题与风险登记册.md](./14-已知问题与风险登记册.md)。

## 7. 升级与回滚

**升级**：`git push` 到 `main` 分支 → Cloudflare Pages 自动部署（1–2 分钟）

**回滚**：
```bash
git revert <commit> && git push     # 推荐
# 或紧急回滚
git reset --hard <上一个好版本> && git push -f
```
